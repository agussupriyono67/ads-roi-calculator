# Ads ROI & ROAS Calculator (Google Ads & Meta Ads)

Aplikasi web interaktif modern untuk mensimulasikan dan menganalisis Return on Ad Spend (ROAS), Return on Investment (ROI), Titik Impas (Break-even ROAS), serta Laba Bersih dari kampanye Google Ads dan Meta Ads.

## Fitur Utama
- **Preset Bisnis Nyata:** ZWCAD Software B2B (High Ticket), Ansys Engineering Project, Meta Ads Lead Gen WhatsApp, dan E-Commerce Retail.
- **Perhitungan Real-time:** Slider dinamis untuk Ad Spend, Volume Closing, Rata-rata Nilai Transaksi (AOV), dan Margin Laba Kotor.
- **Grafik Interaktif:** Visualisasi perbandingan Biaya Iklan vs Laba Kotor vs Laba Bersih menggunakan Chart.js.
- **Ekspor Ringkasan WhatsApp:** Salin laporan rapi ke clipboard atau bagikan langsung ke WhatsApp klien / stakeholder.
- **Desain Modern:** Tema gelap (dark-mode), glassmorphism, responsif untuk desktop dan mobile.
